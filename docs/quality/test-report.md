## 4. 故障与安全演练

- 作业结果跨主机回传：403，拒绝
- 作业重复抢占：第二次返回不可用
- Agent 错误令牌：401
- 快照被篡改：恢复失败并提示校验错误
- 只读模式：写文件/服务/包操作被拒，只读命令放行
- 服务名注入 `nginx; rm -rf /`：被拒绝
- `argv[0]` 携带路径：被拒绝

## 5. 已知缺口

- 作业签名信封、跨主机并发闸门尚未实现
- 包升级与快照恢复尚未在真实 Linux 主机做端到端演练（仅单元与 Windows 冒烟）
- 变更窗口、金丝雀、失败自动回滚编排未实现
- Linux 发行版/Windows 能力矩阵尚未在 UI 展示

## 6. 结论

Phase 1–5 已实现能力通过回归、单元、接口黑盒与关键安全用例验证；可以进入真实主机的小范围灰度。
