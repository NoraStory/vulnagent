## 3. 性能相关结论

- SSH 只读采样共用连接池：性能监控高频轮询不再重复 TCP/认证握手。
- 服务加速探测与系统指标在同一 SSH 连接并发执行；能力探测结果缓存 60 秒，`refresh=1` 强制重采。
- GPU 实时接口只执行一条 `nvidia-smi --query-gpu`，缓存 3 秒；页面 5 秒轮询并在不可见时暂停。
- 节点切换列表只在进入页面时加载，重新检测不再重复请求。
- 备份 gzip 采用多协程分块压缩；并行度按 CPU 核数（最多 8）自动选择。
- 上下文压缩为启发式估算，避免超预算请求；实际 token 数以模型分词器为准。

## 4. 已知缺口

- 真实 NVIDIA GPU 主机上的服务加速、实时运行态与 hashcat 基准需在目标环境验证；无 GPU/未安装 hashcat 时仅返回能力缺失提示。解析与缓存逻辑已通过单元测试与测试 SSH 服务覆盖。
- 多 Agent 的完整链路已通过接口测试覆盖；真实跨网段、长时间心跳与网络抖动需在部署环境观察。
- hashcat 批量审计依赖目标机字典与驱动，未在真实授权环境做端到端演练。
- 浏览器自动化回归受登录态限制，SSH 终端与新增页面目前以用户手工验证为主。
- 服务加速为只读检测与建议，不包含自动调优；基线对比不能替代压测。
- 备份为并行 gzip，未接入 CUDA/nvCOMP，因此不是 GPU 压缩。
