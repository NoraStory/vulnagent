## v0.7.1 · 2026-11-02

**主题**：修复单机 Agent 注册优先级。

### 修复
- 当本机已存在旧 `agent.token` 时，显式传入的 `--enroll-token` 会被忽略；现调整为「显式 `--token` / `--token-file` / `VA_AGENT_TOKEN` > 本机身份 > 一次性注册令牌 > 默认令牌文件」。
- 保证控制面主机自身也能用注册令牌接入，而不误用全局令牌。

### 升级
- 无需迁移；替换二进制后重启 Agent 即可。

**提交**：`8bb196e fix(agents): 显式注册令牌优先于本机旧令牌文件`

## v0.7.0 · 2026-11-02

**主题**：从单机运维扩展到多主机、多集群与多 Agent。

### 新增
- **项目与集群**：项目 → 集群 → 节点模型；节点角色覆盖后端、数据库、缓存、代理、存储与扫描目标。
- **异步检查/扫描**：`cluster_jobs` 后台任务、3 节点并发、进度与逐节点结果、取消与重启中断恢复。
- **数据库深检**：MySQL / PostgreSQL 只读连接，读取版本、连接数、容量与运行时长；凭据 AES-256-GCM 加密、不回显。
- **集群闭环**：项目/集群编辑；资产、漏洞与 P0–P3 跳转；资产/漏洞/报告支持 `clusterId` 筛选。
- **多 Agent 身份**：一次性注册令牌（绑定项目/集群、默认 60 分钟）、Agent ID + 密钥、心跳在线、吊销、`ping` / `collect` 命令通道、资产自动归集。
- **运行配置**：网页调节 AI/GPU、同步/复扫周期、情报源与会话安全项；按角色分级、密钥加密、修改写审计。
- **SSH 服务加速**：GPU/CUDA/功耗/频率与 CPU 调频探测、调优建议、基线对比、hashcat CPU/GPU 基准与批量口令审计。
- **性能与上下文**：SSH 连接复用池、服务加速结果缓存、并行 gzip 备份、Agent 上下文分级压缩与占用展示。
- **体验**：终端主机列表与 AI 面板支持拖拽调宽；问答模式失败后自动继续。

### 迁移
- `0019_ssh_gpu_accel`、`0020_ssh_accel`、`0021_app_settings`、`0022_projects_clusters`、`0023_cluster_jobs`、`0024_cluster_db_checks`、`0025_agents`。
- 既有资产/漏洞不受影响；`assets.cluster_id` 默认 0；旧版全局 Agent 令牌继续可用。

### 兼容性
- 单节点同步检查/扫描接口保留；集群级默认走异步任务。
- 数据库深检为可选项，未配置时行为与旧版 TCP 检查一致。

### 主要提交
`7b38e7c` 外部 CMDB 分页 · `69f9bde` 拖拽调宽 · `73acd2b` 问答自动继续 · `f2ee4fa` 总结排版 · `8907c16` 主机性能监控入口 · `aaae159` 上下文压缩 · `9552903` GPU 推理加速 · `fb856e8` 服务加速探测 · `f35ca1c` SSH 连接池/hashcat/并行 gzip · `d4aacfe` 文档 · `766651e` 运行配置与项目集群 · `11591ba` 异步任务 · `b85b26c` 集群编辑与跳转 · `2bcea95` 数据库深检 · `355d9b2` 多 Agent · `a11028b` 文档同步

## v0.6.0 · 2026-11-01

**主题**：资产发现、拓扑治理、外部集成与性能专项。

### 新增
- **网段发现**：授权网段探活、候选审核、发现任务与资产入库。
- **资产关系与拓扑**：依赖/运行于/成员/管理关系，业务系统 → 资产拓扑视图。
- **资产治理**：责任人缺失、长期未上报、疑似重复、暴露面变化四类待办与批量处理。
- **业务系统权重**：核心/重要/一般参与资产风险加权，调整后即时重算。
- **云与 CMDB 集成**：阿里云 ECS、AWS EC2、Azure VM 只读同步与外部 CMDB JSON API；连接测试、手动/定时同步、失败通知。
- **资产 CMDB**：档案字段、CSV 导入导出、重复资产合并与变更记录。

### 性能与稳定性
- 数据库并发与索引优化、概览统计单查询、HTTP 压缩、前端路由级按需加载。
- 情报快照缓存、匹配与收敛批量写入。
- 漏洞列表计数按需 JOIN assets，补充压测基准与报告。
- 未知 API 路径固定返回 JSON 404，避免前端把 `index.html` 当 JSON 解析。
- 修复复扫状态翻转、合并资产上报、筛选竞态等缺陷。

### 迁移
- `0014_asset_cmdb`、`0015_discovery`、`0016_business_systems`、`0017_integrations`、`0018_performance_indexes`。

## 升级与回滚

1. 升级前执行 `vulnagent backup --out <file>`（可加 `--compress`）。
2. 替换二进制与前端 `web/dist`，重启服务；迁移自动执行。
3. 检查 `/api/v1/healthz`、自检页与 Agent 在线状态。
4. 回滚：停止服务，恢复备份数据库与旧二进制；注意新版本迁移不会自动回退，跨版本回滚需使用对应版本的备份。
