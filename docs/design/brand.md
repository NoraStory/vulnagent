# Signal 品牌规范

## 1. 品牌主张

**Signal / 信号** —— 从信号到结论。

漏洞运营的本质是把海量噪声收敛成可执行结论：先识别信号（CVE、EPSS、在野利用、资产权重），再给出优先级与处置建议，最后留下可审计的痕迹。品牌名与视觉都围绕「信号点」展开。

- 中文名：漏洞信号台
- 英文名：Signal
- 一句话：从信号到结论，可解释、可闭环、可审计。

## 2. 标识

| 资产 | 路径 | 用途 |
|---|---|---|
| 图形标 | `web/public/brand/mark.svg` | 侧边栏、登录页、favicon |
| favicon | `web/public/favicon.svg` | 浏览器标签 |
| PDF 页头 | 复用图形标与墨色标题 | 报告封面 |

图形标结构：

- 墨色 `#101828` 圆角方形（radius 9/32），代表可信的控制面底座。
- 白色双折线 `V`，来自 Vuln，也像一次「收敛」的折返。
- 右上角青绿信号点 `#0E9F8A`，代表实时信号与新鲜度。

横版标识 = 图形标 + 文字「Signal」+ 副标题「漏洞信号台」，文字使用系统无衬线字体，字重 600，字距 -0.01em。

## 3. 色彩

| 角色 | 值 | 说明 |
|---|---|---|
| 页面底色 | `#F6F7F9` | 浅灰，不刺眼 |
| 卡片 | `#FFFFFF` | 与底色形成 1 级层次 |
| 主墨色 | `#101828` | 标题与关键数据 |
| 次级文字 | `#475467` | 正文 |
| 辅助文字 | `#667085` | 说明、时间 |
| 分隔线 | `#E4E7EC` / `#D0D5DD` | 1px 描边，不用重阴影 |
| 信号蓝 | `#2A5BD7`（hover `#1F48B8`，浅底 `#EAEFFC`） | 主操作、选中态 |
| 信号青 | `#0E9F8A` | 实时/在线/只读工具 |
| 成功 | `#12805C` | 已验证、通过 |
| 警示 | `#B54708` | 告警、待审批 |
| 危险 | `#B42318` | P0、失败、拒绝 |

语义映射：P0/P1 用危险/警示色，P2 用琥珀，P3 用中性灰；状态「修复中」用信号蓝，「已验证」用成功绿。

## 4. 字体与排版

- 字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", "PingFang SC", "Microsoft YaHei"`。
- 等宽：`JetBrains Mono, SFMono-Regular, Consolas`，仅用于 CVE、PURL、参数指纹、命令。
- 字号：正文 13px / 行高 21px；页面标题 16.5–17px；指标数字 34px，字距 -0.02em。
- 表格数字启用 `font-feature-settings: "tnum" 1`，保证列对齐。

## 5. 形状与层次

- 圆角：卡片 16px，面板 12px，控件 10px，气泡 14px（一角 6px 表示方向）。
- 阴影：卡片仅用 `0 1px 2px rgba(16,24,40,.04), 0 1px 3px rgba(16,24,40,.06)`；浮层用 `--shadow-float`。
- 分隔优先用 1px 边线，不用重投影；信息密度靠留白与字号对比，而不是装饰。

## 6. 组件约定

- 主按钮：信号蓝实底、白字、h-36；次按钮：白底 + `#D0D5DD` 描边；危险按钮：浅红底 + 深红字。
- 输入框：白底、`#D0D5DD` 描边，聚焦时信号蓝描边 + 15% 透明光环。
- 状态胶囊：`pill` 类，11px，圆角 22px；只表达状态，不承载操作。
- 工具调用：等宽字体小卡片，默认折叠，展开显示脱敏后的 JSON。
- 审批卡：警示色描边 + 浅底，必须显示工具名、风险等级、参数指纹与影响说明。

## 7. 文案语气

- 先结论、后依据；使用「信号 → 结论 → 建议」结构。
- 数字必须来自工具返回，标注来源与 ID（CVE、finding、asset）。
- 不使用夸张形容词；写操作必须说明影响与可逆性。

## 8. 可访问性

- 正文对比度 ≥ 4.5:1，次要文字 ≥ 4.5:1（`#667085` on `#FFFFFF` ≈ 4.8:1）。
- 所有交互元素可键盘聚焦，焦点环 2px 信号蓝。
- 不依赖颜色单独传达状态：状态胶囊同时带文字。

## 9. 设计令牌

颜色、圆角、阴影、字体全部定义在 `web/src/styles/tokens.css`，由 `tailwind.config.js` 映射为语义类名（`bg-page`、`text-ink2`、`border-line`、`bg-brand` 等）。新增颜色必须先加令牌，禁止在页面内写死十六进制。
