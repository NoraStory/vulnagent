# ADR 0004：品牌「Signal / 信号」与浅色极简方向

- 状态：已接受
- 日期：2026-10-24

## 背景

产品缺少品牌资产：无 logo、favicon、登录页叙事；界面更像内部工具而非可交付产品。

## 决策

- 保留产品名 `VulnAgent`，中文副标题「漏洞运维智能体」。
- 品牌概念：**Signal / 信号**，主张「从信号到结论」。
- 视觉：浅色、精致、极简；墨色文字 + 信号蓝 `#2A5BD7` + 辅助青 `#0E9F8A`；无渐变、无霓虹。
- 标志：圆角方形墨色底 + 白色双折线 “V” + 右上信号点；同时提供横版标志与 favicon。
- 语气：结论先行、动词开头、错误文案给下一步。
- 登录页承载品牌叙事；PDF 报告页头复用同一品牌。

## 后果

- 需要新增 `docs/design/brand.md` 与 SVG 资产。
- 前端所有页面按新令牌重绘；旧视觉一次性替换。
